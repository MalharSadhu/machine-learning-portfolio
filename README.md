## 🛠️ Environment & Reproducibility

To replicate this laboratory locally, clone the repository and install the verified dependencies:

```bash
git clone [https://github.com/MalharSadhu/machine-learning-portfolio.git](https://github.com/MalharSadhu/machine-learning-portfolio.git)
cd machine-learning-portfolio
pip install numpy pandas matplotlib seaborn scipy scikit-learn tabulate
```
