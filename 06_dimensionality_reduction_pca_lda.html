Compressing Reality: Unsupervised PCA vs. Supervised LDA in Latent Feature Spaces¶

In modern data science, datasets routinely contain dozens, hundreds, or thousands of features. This wealth of information comes at a steep price known as the Curse of Dimensionality:

  • Exponential growth in sample space volume causes data points to become equidistant and sparse.
  • Multicollinearity destabilizes model weights.
  • Humans cannot visualize geometry beyond three spatial dimensions.

How do we compress high-dimensional feature spaces into 2D or 3D projections without destroying crucial diagnostic information?

In this sixth module, we contrast two foundational dimensionality reduction paradigms:

  • Principal Component Analysis (PCA): An unsupervised geometric technique that maximizes global variance without knowing class labels.
  • Linear Discriminant Analysis (LDA): A supervised probabilistic technique that discovers axes maximizing the ratio of between-class variance to within-class variance.

1. The Dataset: Multi-Dimensional Wine Chemometrics¶

We evaluate PCA and LDA on the 13-dimensional Wine Dataset from scikit-learn ($n=178$, $p=13$ continuous chemical assays, $C=3$ grape cultivars).

Reducing 13 continuous chemical dimensions down to 2 latent dimensions enables us to visually inspect how each technique compresses information.

2. Exploratory Data Analysis: Variance Inequality Across Features¶

PCA projects data onto orthogonal eigenvectors of the covariance matrix. Because eigenvectors point in the direction of maximum numeric spread, variables with large raw scales will artificially dominate the principal components if left unscaled.

3. Statistical Testing: Bartlett's Test of Sphericity¶

Before applying PCA, we verify whether the variables are sufficiently correlated to warrant dimension reduction in the first place:

  • Null Hypothesis ($H_0$): The correlation matrix is an identity matrix (variables are completely orthogonal/uncorrelated; PCA is meaningless).
  • Alternative Hypothesis ($H_1$): Significant inter-variable correlation exists, justifying dimensionality reduction.
In [3]:
# Standardize features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Bartlett's test approximation via determinant of correlation matrix
corr_mat = np.corrcoef(X_scaled, rowvar=False)
n, p = X_scaled.shape
det_corr = np.linalg.det(corr_mat)
chi2_stat = - (n - 1 - (2 * p + 5) / 6) * np.log(det_corr)
df_chi = p * (p - 1) / 2
p_val_bartlett = stats.chi2.sf(chi2_stat, df_chi)

print(f"Bartlett's Test Chi-Square Statistic : {chi2_stat:.2f}")
print(f"Degrees of Freedom                   : {int(df_chi)}")
print(f"p-value                              : {p_val_bartlett:.2e}")
print(f"Reject H0 (Suitable for Reduction)?  : {'YES' if p_val_bartlett < 0.001 else 'NO'}")

4. Algorithmic Mechanics: Unsupervised PCA vs. Supervised LDA¶

1. Principal Component Analysis (Unsupervised)¶

PCA seeks an orthogonal projection matrix $\mathbf{W}$ that maximizes sample variance without access to class labels:

$$\mathbf{\Sigma} = \frac{1}{n-1} \mathbf{X}^T \mathbf{X}, \quad \mathbf{\Sigma} \mathbf{v}_i = \lambda_i \mathbf{v}_i$$

  • Each component $\mathbf{v}_i$ is an eigenvector corresponding to eigenvalue $\lambda_i$, representing the variance explained by that axis.

2. Linear Discriminant Analysis (Supervised)¶

LDA uses class labels $y \in \{1, \dots, C\}$ to find projection vectors $\mathbf{w}$ that maximize Fisher's criterion (between-class scatter $\mathbf{S}_B$ over within-class scatter $\mathbf{S}_W$):

$$J(\mathbf{w}) = \frac{\mathbf{w}^T \mathbf{S}_B \mathbf{w}}{\mathbf{w}^T \mathbf{S}_W \mathbf{w}}$$

  • LDA is constrained to at most $C - 1$ discriminant dimensions (for 3 cultivars, exactly 2 components).
In [4]:
# 1. Fit Unsupervised PCA (Keep all 13 to inspect explained variance curve)
pca = PCA(random_state=42)
X_pca = pca.fit_transform(X_scaled)
explained_var_ratio = pca.explained_variance_ratio_
cum_var = np.cumsum(explained_var_ratio) * 100

# 2. Fit Supervised LDA (Max components = n_classes - 1 = 2)
lda = LDA(n_components=2)
X_lda = lda.fit_transform(X_scaled, y)

# 3. Train downstream classifiers on 2D embeddings to measure information retention
X_train_pca, X_test_pca, y_train, y_test = train_test_split(X_pca[:, :2], y, test_size=0.3, random_state=42, stratify=y)
X_train_lda, X_test_lda, _, _ = train_test_split(X_lda, y, test_size=0.3, random_state=42, stratify=y)

clf_pca = LogisticRegression().fit(X_train_pca, y_train)
clf_lda = LogisticRegression().fit(X_train_lda, y_train)

acc_pca_2d = accuracy_score(y_test, clf_pca.predict(X_test_pca)) * 100
acc_lda_2d = accuracy_score(y_test, clf_lda.predict(X_test_lda)) * 100

6. Real-World Insights & Synthesis¶

1. Unsupervised Exploration vs. Targeted Discrimination¶

  • PCA (Panel B): Finds directions of maximum spread across all data points regardless of category. While it clusters the cultivars reasonably well, the boundaries remain softly merged because PCA doesn't know class identities.
  • LDA (Panel C): Explicitly constructs projection axes that pull identical classes together while pushing distinct cultivars apart. The resulting clusters are tighter and isolated, producing higher downstream classification accuracy.

2. When to Use Which?¶

  • Use PCA when exploring unlabeled datasets, denoising data, compressing features for unsupervised clustering, or avoiding multicollinearity in regression.
  • Use LDA when class labels exist and the explicit goal is maximizing class separation for low-dimensional visualization or classification.
